# 电缸运动控制程序说明与 PLC 移植参考

本文按当前 STM32 源码整理，重点说明已实现的控制逻辑、主要功能块及其输入、输出、互锁和完成条件。

## 1. 当前功能与基本概念

程序通过脉冲加方向控制一个运动轴，主要交互入口为串口屏。

| 功能 | 当前行为 |
| --- | --- |
| 上电机械回零 | 自动负向运动寻找 PB15（磁性开关），确认后建立位置零点 |
| 正、反向定长点动 | 每次点击移动设定距离，默认 1 mm，速度 100 mm/s |
| 运行1 | 按余弦位置曲线连续往复，可在停止时设置频率和幅值 |
| 运行2 | 按照有杂散的扰动的正余弦运动 |
| 结束运行 | 运行中再次按运行1或运行2，停止曲线并返回本次运行起点 |
| 最大限位处理 | PB13 触发后停止当前动作并执行 PB15 机械回零，回零类动作期间有例外 |
| 状态上传 | 上传位置、参数、状态，并控制回零页切换 |

当前 User/AppConfig.h 配置：APP_ENABLE_HMI=1，APP_ENABLE_KEY=0，APP_ENABLE_OLED=0。串口屏启用，本地按键与 OLED 停用，因此 ui_mode 保持运行模式。

必须区分三个位置概念：

- **机械零点**：PB15 持续有效后确定的 0 mm。
- **运行起点 S**：每次启动简谐运行时记录的当前位置，可以不是 0 mm。
- **当前位置**：程序累计已发送脉冲得到的位置，没有编码器实测反馈。

例如：先点动到 50 mm，再启动运行1，运行起点就是 50 mm；结束运行后返回 50 mm。机械回零则重新寻找 PB15，并将坐标清为 0 mm。

## 2. 硬件、单位和参数

### 2.1 输入输出映射

| STM32 资源 | 含义 | 有效条件 / 用途 | PLC 对应角色 |
| --- | --- | --- | --- |
| PB15 | 机械零点输入 | 低电平有效；平时约 3.3 V，外部已有上拉，代码配置浮空输入 | 零点数字输入 |
| PB13 | 最大限位输入 | 高电平有效，外部已有上拉，代码配置浮空输入 | 最大限位数字输入 |
| PA0 / TIM2_CH1 | 脉冲输出 | 高有效脉冲，停止时强制低电平 | 高速脉冲输出通道 |
| PB10 | 方向输出 | 高：正向、位置增加；低：负向、位置减少 | 方向输出 |
| PA9 / USART1_TX | 发给串口屏 | 115200、8N1、无流控 | 串口发送 |
| PA10 / USART1_RX | 接收串口屏 | 115200、8N1、无流控 | 串口接收 |

程序没有驱动器使能输出控制、驱动器报警输入处理或编码器反馈处理。

### 2.2 位置换算

源码实际换算为：

```text
每转脉冲数 = 2000 pulse/rev
导程       = 20 mm/rev
每毫米脉冲 = 2000 / 20 = 100 pulse/mm
1 pulse    = 0.01 mm
最大行程   = 950 mm = 95000 pulse
```

源码注释写有“齿轮比 5:1”，但换算公式中没有额外乘除 5。移植前应按实际传动与驱动器细分核对比例；照搬当前程序时使用的是 **100 pulse/mm**。

### 2.3 主要参数

| 参数 | 默认值 | 范围 / 步长 | 作用 |
| --- | --- | --- | --- |
| 简谐频率 f | 0.21 Hz | 0.01～2.00 Hz；加减步长 0.01 Hz | 周期 T=1/f |
| 简谐幅值 A | 200 mm | 10～470 mm；加减步长 10 mm | 实际往复距离是 2A |
| 单次点动距离 | 1 mm | 1～100 mm；加减步长 1 mm | 串口屏一次点动距离 |
| 点动、机械回零、返回起点速度 | 100 mm/s | 源码常量 | 对应 10 kHz 脉冲 |
| 简谐脉冲批次频率 | 100 kHz | 源码常量 | 每批增量以此频率发完，批次之间可能停顿 |
| 随机基础扰动 | ±10 mm | 源码常量 | 作用于幅值 A |
| 随机干扰强度 | 100% | 接口支持 0～100%，加减步长 5% | 当前串口协议未提供调整入口 |
| 随机更新间隔 | 100 ms | 源码常量 | 到期且执行轨迹计算时更新 |
| 零点确认时间 | 20 ms | 源码常量 | PB15 连续低电平确认 |
| 机械回零超时 | 12 s | 源码常量 | 从机械回零开始计时，包含确认等待 |
| 时间基准 | 500 μs | TIM3 中断累计 | 轨迹时间最小分辨率 |
| 状态刷新周期 | 100 ms | 主循环判断 | 另有命令和状态变化触发的即时刷新 |

直接写参数与加减按钮的精度不同：B2 可按 0.01 mm 写入幅值，加减按钮每次改变 10 mm。设置接口把越界值限制到上下限，不因参数越界直接报错。参数不写入 Flash，复位后恢复源码默认值。

## 3. 程序总体执行顺序

### 3.1 初始化

```text
main → SystemInit → App_Init
  → 初始化已启用的按键
  → Motor_Init：方向、限位输入、脉冲定时器
  → Timebase_Init：启动 500 μs 时基
  → HMI_Init：串口及接收缓存
  → Motor_StartStartupHoming：立即启动机械回零
  → UI_Init / UI_Update：选择 page2 并上传状态
  → 循环执行 App_Process
```

### 3.2 每次主循环

1. 读取时间，优先处理 PB13 最大限位。
2. 机械回零期间处理 PB15 检测、20 ms 确认和 12 s 超时。
3. 接收并分发串口屏命令；按键启用时扫描和处理本地操作。
4. 若返回起点的脉冲已发完，结束返回状态。
5. 时间值变化、简谐运行启用且没有发送中的脉冲批次时，计算下一批轨迹增量。
6. 每 100 ms 刷新界面状态。

运动流程采用非阻塞处理：TIM2 输出脉冲，中断每完成一个脉冲累计位置，主循环同时处理限位和通信。串口状态发送逐字节等待发送完成，会占用主循环时间。

PLC 可保留上述扫描顺序，把脉冲输出交给高速脉冲硬件或运动轴功能，不应通过普通扫描逐个翻转输出点复制 TIM2 中断。

下面的 FB_* 名称表示建议的逻辑边界。现有工程主要把运动逻辑集中在 Hardware/Motor.c，并没有这些独立 PLC 功能块。

| --- | --- | --- | --- |
| FB_AxisSupervisor 轴管理 | App_Process、App_ProcessHMI | 操作请求、限位、各动作忙状态 | 启停请求、命令互锁 |
| FB_Home 机械回零 | Motor_StartStartupHoming、Motor_ProcessStartupHoming | 启动、PB15、时间 | 负向运动、忙、完成清零、超时 |
| FB_MaxLimit 最大限位 | Motor_ProcessMaxLimit | PB13、机械回零忙、返回起点忙 | 停止并启动机械回零、触发锁存 |
| FB_JogStep 定长点动 | Motor_JogStep | 方向、距离、当前位置 | 限幅后的相对位移请求 |
| FB_Harmonic 简谐轨迹 | Motor_StartMotion、Motor_Update、Motor_FitsTravel | 启动、时间、A、f、起点 | 目标位置、脉冲增量、行程错误 |
| FB_RandomAmplitude 随机幅值 | Motor_SetRandomEnabled、Motor_RandomDisturbancePulses | 使能、强度、时间 | 随机幅值扰动 |

| FB_PulseAxis 脉冲执行 | Motor_SendPulses、TIM2_IRQHandler | 有符号脉冲数、频率、停止 | 方向、脉冲、忙、累计位置 |
| FB_HMI 命令和状态 | HMI.c、UI.c | 接收字节、轴状态 | 命令事件、E0/E1 数据 |

### 4.1 机械回零：FB_Home

触发源是上电初始化或最大限位请求。

```text
开始 → 停止当前动作，清除行程错误，记录开始时间
  ├─ PB15 已低：不发脉冲，直接进入零点确认
  └─ PB15 为高：以 100 mm/s 向负方向连续运动

寻找中 → PB15 首次变低：立即停脉冲，开始 20 ms 确认
确认中 → PB15 回高：取消确认，继续向负方向寻找
确认中 → 持续高满 20 ms：结束回零并清零坐标
未完成 → 总耗时达到 12 s：停止，设置行程错误
```

完成时清零 current_position、pos_float 和 motion_start_position。回零期间不累计软件位置、不检查软件位置下限，屏幕位置固定显示 0.00 mm。

该流程没有离开零点后再次慢速接近的步骤，停脉冲后确认信号即可完成。PLC 可用步骤状态配合 20 ms、12 s 定时器实现，保留“首次看到零点先停止，再确认”的顺序。

### 4.2 最大限位：FB_MaxLimit

PB13 高电平有效。主循环读到有效且尚未锁存时，调用机械回零启动函数：先停止当前动作，再向 PB15 寻零。

- PB13 没有触发前消抖。
- max_limit_latched 防止持续高电平重复触发，读到低电平解除锁存。
- **机械回零或返回运行起点期间，仅更新 PB13 锁存状态，不重新触发机械回零。**

PLC 对应“有效且未锁存”的事件处理，配合机械回零和返回起点忙互锁。当前响应发生在主循环读取输入时，并非外部中断硬件停机。

### 4.3 定长点动：FB_JogStep

串口屏 C3 正向、C4 反向，每条命令触发一次。

1. 简谐运行、返回起点、连续按键点动或脉冲批次执行中，不启动新点动。
2. 设定距离乘以 100 得到脉冲数；正向为正，反向为负。
3. 目标超出 0～950 mm 时，将本次距离缩短到软件边界。
4. 以 10 kHz 发送定量脉冲，发完回到空闲。

例如当前位置 948 mm，正向点动设为 10 mm，实际只发送 200 脉冲，停在 950 mm。已在同向边界时不发送脉冲，也不设置行程错误。

串口屏定长点动使用 sending 标志，jog_active 主要用于停用中的本地连续点动。PLC 对外可统一显示点动，但应区分“按一次走固定距离”与“按住持续走”。

### 4.4 普通简谐运动：FB_Harmonic

启动时记录当前位置 S、当前时刻，将初始已规划位置设为 S。运行1先关闭随机，再检查：

```text
S ≥ 0
S + 2A ≤ 950 mm
```

不满足则拒绝启动并设置行程错误。成功后按绝对时间计算目标位置：

```text
t = 当前时间 - 本次启动时间，单位 s
x(t) = S + A × [1 - cos(2πft)]
```

| 时刻 | 目标位置 | 含义 |
| --- | --- | --- |
| 0 | S | 从起点启动 |
| T/4 | S+A | 正向经过中间位置 |
| T/2 | S+2A | 到达上端点 |
| 3T/4 | S+A | 负向经过中间位置 |
| T | S | 完成一周期，继续下个周期 |

默认 S=0、A=200 mm、f=0.21 Hz 时，目标范围 0～400 mm，周期约 4.762 s。A 是围绕中间位置的幅值，峰峰行程是 2A。

实际发送算法使用脉冲单位：

```text
目标脉冲位置 = S_pulse + A_pulse × [1 - cos(2πft)]
增量 = 目标脉冲位置 - pos_float
本次脉冲数 = 增量按正负四舍五入到整数
pos_float += 本次脉冲数
以 100 kHz 发送这一批有符号脉冲
```

pos_float 是已交给发送器的规划位置；current_position 是中断累计的已发脉冲位置，批次执行中二者不同。主循环等批次发完才再次计算，不会每 500 μs 强制排入一个批次；忙时跳过的计算点不会逐一补算。

PLC 需要保留“绝对时间算目标位置”的含义，并明确目标的执行方式。若改用连续位置给定、插补或带加减速的定位，实际脉冲行为会与当前分批发送方式不同。

### 4.6 返回运行起点：FB_ReturnStart

触发源为运行中 C1/C2，或命令允许状态下的 D1。

1. Motor_Stop 立即停脉冲，取消当前动作及待发送批次。
2. 计算 motion_start_position-current_position。
3. 差值非零时置 return_active，以 100 mm/s 发送对应脉冲。
4. 主循环发现 return_active=1 且 sending=0，清除返回状态。

此过程不寻找 PB15、不重新清零，也没有机械回零的 12 s 超时。完成后软件位置等于保存的 S。没有减速停车过程，返回采用固定频率脉冲。

### 4.7 里程累积：FB_PulseAxis

- 有符号脉冲数确定方向，绝对值确定批次数量。
- TIM2 更新事件对应脉冲周期结束，每完成一脉冲，软件位置加 1 或减 1。
- 发够数量即停止，停止时强制 PA0 低电平。
- Motor_Stop 清除动作忙状态和待发送增量，保留当前位置、运行起点、参数、随机使能和已有错误。
- 内部支持将忙时收到的增量累积到 pending_delta；当前简谐主循环有 !sending 互锁，通常不走此排队路径。
- 机械回零不累计位置；连续按键点动逐脉冲检查软件边界；定长点动在请求发出前限幅。

PLC 对应块需要相对脉冲量、方向、频率、忙、完成和立即停止语义。软件位置应跟随已输出脉冲或轴的命令位置，不能在运动未完成时直接把目标当作当前位置。

## 5. 命令互锁和状态转换

### 5.1 当前串口入口互锁

| 当前动作 | 参数 A1～A6 / B1～B3 | C1 / C2 | C3 / C4 | D1 |
| --- | --- | --- | --- | --- |
| 机械回零 | 忽略 | 忽略 | 忽略 | 忽略 |
| 简谐运行1或2 | 忽略 | 停曲线并返回保存起点 | 忽略 | 忽略 |
| 定长点动未完成 | 允许设置，影响后续动作 | 忽略 | 不启动新点动 | 中断点动并返回保存起点 |
| 返回运行起点 | 允许设置，影响后续动作 | 忽略 | 不启动新点动 | 按当前位置重新计算返回 |
| 空闲 | 允许 | 通过行程检查后启动运行 | 执行一次定长点动 | 返回保存起点 |

特别说明：

- D1 注释虽为“停止运动”，实现是返回起点，并且在简谐运行期间被入口过滤。运行中由 C1/C2 结束运行。
- C1 注释虽写“回零”，实际在空闲启动普通简谐，在运行中返回起点。
- D1 在没有进行过简谐运行时也使用已有起点变量，机械回零成功后该变量为 0。
- 命令被分发并回传状态不等于成功启动动作；忙状态或行程检查可能导致没有产生运动。

### 5.2 典型转换

```text
上电 → 机械回零 → 确认零点 → 空闲
                  └─ 超时 → 错误状态显示
空闲 → C3/C4 → 定长点动 → 脉冲完成 → 空闲
空闲 → C1 → 运行1 → C1或C2 → 返回运行起点 → 空闲
空闲 → C2 → 运行2 → C1或C2 → 返回运行起点 → 空闲
非机械回零、非返回起点状态 → PB13首次有效 → 机械回零
```

以上是对现有标志组合的整理，源码没有单一状态枚举。显示错误不等于进入禁止运动状态，见第 8 节。

## 6. HMI 通信与状态块

保留当前串口屏时使用本节协议。PLC 改用其他 HMI 通信方式时，可保留相同变量和按钮事件，不必复制 STM32 DMA 实现。

### 6.1 帧格式与接收

```text
55 AA CMD LEN DATA...
```

多字节数据小端，LEN 最大 16；没有校验和、帧尾、序号或解析超时。

接收路径：USART1 DMA 普通模式缓冲 64 字节 → IDLE 中断搬运 → 128 字节环形缓存 → 主循环逐字节解析 → 帧队列 → 命令分发。

环形缓存实际最多存 127 字节；帧队列数组长度 4，实际最多存 3 帧，满时丢弃新数据。DMA 依靠空闲中断重新装载，不是无限连续接收。

### 6.2 屏幕到控制器

| CMD | LEN | 数据及行为 |
| --- | --- | --- |
| A1 / A2 | 0 | 频率加 / 减 0.01 Hz |
| A3 / A4 | 0 | 简谐幅值加 / 减 10 mm |
| A5 / A6 | 0 | 点动距离加 / 减 1 mm |
| B1 | 2 | UINT16，频率 ×100，单位 0.01 Hz |
| B2 | 2 | UINT16，简谐幅值 ×100，单位 0.01 mm |
| B3 | 2 | UINT16，点动距离，单位 mm |
| C1 | 0 | 空闲启动运行1；运行中返回起点 |
| C2 | 0 | 空闲启动运行2；运行中返回起点 |
| C3 / C4 | 0 | 正向 / 反向定长点动 |
| D1 | 0 | 返回保存起点，受第 5 节互锁约束 |

例如设置频率 0.21 Hz：55 AA B1 02 15 00；设置点动距离 10 mm：55 AA B3 02 0A 00。未知命令和长度不符的命令不执行，没有单独错误应答帧。

### 6.3 控制器到屏幕

页面帧：55 AA E0 01 PAGE。

- PAGE=02：机械回零或返回起点，显示 page2。
- PAGE=00：上述动作结束，显示 page0。
- 当前控制器代码没有发送 page1 的逻辑。

状态帧：

```text
55 AA E1 0A STATE POS0 POS1 POS2 POS3 FREQ0 FREQ1 AMP0 AMP1 JOG
```

| 数据区偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | BYTE | 状态码 |
| 1～4 | 32 位小端整数 | 位置，单位 0.01 mm，正常坐标非负 |
| 5～6 | UINT16，小端 | 频率，单位 0.01 Hz |
| 7～8 | UINT16，小端 | 简谐幅值，单位 0.01 mm |
| 9 | BYTE | 点动距离，单位 mm |

位置 getter 返回有符号 32 位值，UI 转成无符号 32 位后按字节打包，正常 0～950 mm 范围内两种解释一致。机械回零期间位置字段强制 0，返回运行起点期间上传累计位置。

| 状态码 | 含义 | 显示优先级 |
| --- | --- | --- |
| 4 | 行程错误或机械回零超时 | 最高 |
| 3 | 机械回零或返回运行起点 | 次高 |
| 2 | 运行2 | 之后依次判断 |
| 1 | 运行1 | 之后依次判断 |
| 5 | 连续点动或正在发送脉冲 | 之后依次判断 |
| 0 | 空闲 | 无以上状态 |

E1 每 100 ms 上传，也在被分发的有效命令和部分状态变化后立即上传，同时承担操作反馈，没有独立“启动成功”确认字段。E0 在初始化及回零类忙状态变化时发送，避免周期刷新重复切页。

PLC 按钮请求宜作为单次事件交给轴管理块，避免保持为真的按钮每扫描周期重复启动。当前串口屏每次点击发一条帧，不能直接等同于持续电平。

最小移植顺序与验证目标：

1. 输入输出、脉冲比例及完成计数：验证 100 脉冲对应 1 mm、正负方向正确。
2. 机械回零和最大限位：验证首次零点停止、20 ms 确认、抖动恢复、12 s 超时及触发锁存。
3. 定长点动和返回起点：验证边界缩短距离、忙互锁，以及返回的是保存的 S。
4. 普通简谐：验证 T/4、T/2、T 时的位置及启动前行程检查。
5. 随机幅值：验证 100 ms 更新及运行2额外行程预留。
6. HMI：逐项验证命令互锁、参数单位、状态码和页面转换。

## 8. 移植前应明确的现有实现边界

以下是源码当前行为，不是已经完成的改进项：

- **没有回零完成有效标志。** 回零超时后仅设置错误，没有全局禁止启动互锁，后续动作仍按自身条件判断。若 PLC 要求未成功回零禁止运行，需要增加坐标有效条件。
- **错误标志不是运动总锁。** 点动不自动清除已有错误，屏幕可能仍显示 4；成功启动简谐、成功机械回零等路径会清错，没有独立故障复位命令。
- **PB15 仅用于机械回零检测。** 普通运动下限主要依赖软件坐标；PB13 在返回运行起点期间也不重新触发机械回零。
- **行程保护分散在不同路径。** 简谐启动前检查范围，定长点动发出前限幅，连续按键点动逐脉冲检查边界；通用定量脉冲中断没有统一的每脉冲行程检查。
- **频率与幅值只分别限幅。** 没有组合速度 / 加速度校验。普通曲线理论峰值速度为 2πfA；A=470 mm、f=2 Hz 时约 5906 mm/s，对应约 591 kpulse/s，超过当前 100 kHz 批次输出能力，参数合法不代表实际能跟随轨迹。
- **时间为 32 位微秒计数。** 约 71.58 分钟回绕；短时差使用无符号减法，但单次简谐连续运行跨完整计数周期后，相位时间会回绕，不能假定无限长运行。
- **没有持久化、闭环位置校验或断电恢复逻辑。** 位置是脉冲命令累计值，机械失步不会由此自动检出。

PLC 若增加互锁或使用加减速定位，应在验收时区分复现当前逻辑与改变运动行为，重新核对起点返回、限位及轨迹跟随结果。
