# STM32F103 电缸简谐运动控制

这是一个基于 `STM32F103C8`、STM32F10x 标准外设库和 Keil MDK 的电缸控制工程。系统通过串口屏设置运动参数和发送控制命令，使用 `TIM2_CH1` 输出步进脉冲，并支持开机机械回零、最大限位保护、定长点动、简谐运行和随机扰动运行。

本地 OLED 和按键目前停用，功能开关位于 `User/AppConfig.h`。

## 当前功能

- 串口屏作为主要交互界面，上电先进入回零页，机械回零完成后进入运行页。
- USART1 使用 DMA 接收和串口空闲中断确定本批数据长度。
- 使用自定义二进制协议，支持命令解析、帧头重新同步和多帧缓存。
- 支持运行1（普通简谐运动）和运行2（带随机扰动的简谐运动）。
- 运行期间只接受运行1、运行2按钮命令，按任意一个都会结束当前运行并返回运行起点。
- 点动幅值可由串口屏设置，范围 `1～100 mm`，默认 `1 mm`。
- 上电后自动向下寻找 PB12 机械零点，完成后建立相对坐标零点。
- PB13 最大限位触发后立即停止当前运动，并重新向下寻找 PB12 机械零点。
- 开机或最大限位机械回零时进入 `page2` 并显示 `0.00 mm`；普通返回起点时持续显示当前位置，完成后返回 `page0`。
- 支持 `0～950 mm` 软件行程保护和回零超时保护。

## 硬件连接

| 引脚 | 功能 | 说明 |
| --- | --- | --- |
| `PA0` | `TIM2_CH1` | 步进驱动器脉冲输出 |
| `PB10` | DIR | 高电平向上，低电平向下 |
| `PB12` | 零点光耦输入 | 浮空输入，高电平表示零点信号有效 |
| `PB13` | 最大限位光耦输入 | 浮空输入，高电平表示最大限位有效 |
| `PA9` | USART1_TX | 连接串口屏 RX |
| `PA10` | USART1_RX | 连接串口屏 TX |

单片机和串口屏必须共地。PB12、PB13 按当前硬件约定使用高电平有效逻辑。

## 串口配置

```text
USART：USART1
波特率：115200
数据位：8
停止位：1
校验位：无
流控：无
接收：DMA1 Channel5 + USART1 IDLE中断
```

DMA 缓冲区为 64 字节，软件环形缓冲区为 128 字节，协议单帧数据区最大为 16 字节。

## 自定义协议

统一帧格式：

```text
55 AA CMD LEN DATA...
```

- `55 AA`：帧头。
- `CMD`：命令字。
- `LEN`：数据长度，范围 `0～16`。
- `DATA`：数据区；多字节整数使用小端序。
- 当前协议没有校验和。

### 串口屏发给下位机

| 命令 | 数据 | 功能 |
| --- | --- | --- |
| `A1` | 无 | 频率增加 `0.01 Hz` |
| `A2` | 无 | 频率减少 `0.01 Hz` |
| `A3` | 无 | 运动振幅增加 `10 mm` |
| `A4` | 无 | 运动振幅减少 `10 mm` |
| `A5` | 无 | 点动幅值增加 `1 mm` |
| `A6` | 无 | 点动幅值减少 `1 mm` |
| `B1` | `uint16` | 设置频率，单位 `0.01 Hz` |
| `B2` | `uint16` | 设置运动振幅，单位 `0.01 mm` |
| `B3` | `uint16` | 设置点动幅值，单位 `mm` |
| `C1` | 无 | 空闲时启动运行1；运行中停止并返回运行起点 |
| `C2` | 无 | 空闲时启动运行2；运行中停止并返回运行起点 |
| `C3` | 无 | 正向点动一次 |
| `C4` | 无 | 反向点动一次 |
| `D1` | 无 | 返回运行起点 |

示例：把点动幅值设置为 `10 mm`：

```text
55 AA B3 02 0A 00
```

### 下位机发给串口屏

#### E0：页面切换

```text
55 AA E0 01 PAGE
```

| PAGE | 页面 |
| ---: | --- |
| `00` | `page0` 运行页 |
| `01` | `page1` 参数页 |
| `02` | `page2` 回零页 |

#### E1：状态帧

下位机每 `100 ms` 周期发送一次，也会在有效命令执行后立即发送。

```text
55 AA E1 0A STATE POS0 POS1 POS2 POS3 FREQ0 FREQ1 AMP0 AMP1 JOG
```

| 字段 | 长度 | 含义 |
| --- | ---: | --- |
| `STATE` | 1 | 当前状态 |
| `POS` | 4 | 当前位置，`int32` 小端，单位 `0.01 mm` |
| `FREQ` | 2 | 当前频率，`uint16` 小端，单位 `0.01 Hz` |
| `AMP` | 2 | 当前运动振幅，`uint16` 小端，单位 `0.01 mm` |
| `JOG` | 1 | 当前点动幅值，单位 `mm` |

状态码：

| 状态码 | 含义 |
| ---: | --- |
| `0` | 空闲 |
| `1` | 运行1 |
| `2` | 运行2 |
| `3` | 开机回零或返回起点 |
| `4` | 行程或回零超时错误 |
| `5` | 点动 |

## 回零和限位逻辑

### 开机回零

1. 外设初始化完成后进入 `page2`。
2. PB10 输出低电平，电机以 `100 mm/s` 向下运动。
3. 首次检测到 PB12 高电平时立即停止脉冲。
4. PB12 持续高电平 `20 ms` 后确认回零完成。
5. 将当前位置、运动浮点位置和运动起点全部设为相对坐标 `0`。
6. 返回 `page0`。

回零超过 `12 s` 仍未确认 PB12 时，程序停止电机并上报状态 `4`。

### 最大限位

PB13 高电平时，程序在主循环最高优先级执行以下处理：

1. 立即停止当前脉冲输出。
2. 停止简谐运行或点动。
3. 进入 `page2`。
4. 向下运行并通过 PB12 重新寻找机械零点。
5. 回零期间忽略 PB13，PB13 恢复低电平后才允许再次触发。

## 运动参数

主要参数定义在 `Hardware/Motor.c`。

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `MOTION_AMPLITUDE_MM` | `200.0f` | 默认运动振幅，单位 mm |
| `MOTION_AMPLITUDE_MIN/MAX/STEP` | `10 / 470 / 10` | 运动振幅范围和调节步长，单位 mm |
| `MOTION_FREQUENCY` | `0.21f` | 默认频率，单位 Hz |
| `MOTION_FREQUENCY_MIN/MAX/STEP` | `0.01 / 2.00 / 0.01` | 频率范围和调节步长，单位 Hz |
| `RANDOM_DISTURBANCE_MM` | `10.0f` | 运行2随机扰动幅值，单位 mm |
| `JOG_SPEED_MMPS` | `100.0f` | 点动和机械回零速度，单位 mm/s |
| `JOG_AMPLITUDE_MIN/MAX` | `1 / 100` | 单次点动幅值范围，单位 mm |
| `PULSES_PER_REV` | `2000` | 每转脉冲数 |
| `LEAD_SCREW_PITCH` | `20.0f` | 丝杆导程，单位 mm/rev |
| `PULSES_PER_MM` | `100` | 每毫米脉冲数 |
| `MAX_TRAVEL_MM` | `950.0f` | 软件最大行程，单位 mm |

当前简谐目标位置公式：

```c
target = start + amplitude * (1 - cos(2 * PI * frequency * time));
```

因此实际位置范围为 `start～start + 2 × amplitude`。启动前会检查整个运动范围是否超过 `950 mm`；运行2还会额外预留随机扰动空间。

## 软件结构

| 文件 | 作用 |
| --- | --- |
| `User/main.c` | 系统入口 |
| `User/App.c` | 应用状态机、串口屏命令分发和安全处理顺序 |
| `User/AppConfig.h` | OLED、按键、串口屏功能开关 |
| `User/UI.c` | E0页面控制和E1状态上传 |
| `Hardware/HMI.c` | USART1、DMA、空闲中断和自定义协议解析 |
| `Hardware/Motor.c` | 脉冲输出、运动计算、点动、回零和限位逻辑 |
| `System/Timebase.c` | TIM3 产生 `500 us` 非阻塞时间基准 |
| `Project.uvprojx` | Keil MDK 工程文件 |

串口屏工程文件未纳入 Git 跟踪，屏端需要启用主动解析模式 `recmod=1`，并在各页面定时器中解析 E0/E1 数据。

## 构建

使用 Keil MDK 打开 `Project.uvprojx` 并构建 `Target 1`。

当前工程配置：

- 芯片：`STM32F103C8`
- 内核：Cortex-M3
- 库：STM32F10x Standard Peripheral Library
- 宏：`USE_STDPERIPH_DRIVER`
- 输出目录：`Objects`
- 输出文件：`Project.axf`
- `CreateHexFile=0`，默认不生成 HEX；需要 HEX 时请在 Keil 中开启生成选项。

最近一次完整构建结果：

```text
0 Error(s), 0 Warning(s)
```

## 上电测试建议

首次联机建议先断开电机动力，只观察方向、脉冲、PB12/PB13 电平和页面切换：

1. PB12 为低、PB13 为低时上电，应进入 `page2` 并输出向下脉冲。
2. PB12 变为高电平后，应立即停止，约 `20 ms` 后进入 `page0`。
3. 正常运行时将 PB13 置高，应立即停止并重新进入机械回零。
4. 确认方向和限位逻辑正确后再接通电机动力。
